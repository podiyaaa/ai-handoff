# Marketplace icon

This directory needs an `icon.png` (128×128, PNG format) before publishing to the VS Code Marketplace.

You can:

1. Design one yourself (Figma, Sketch, etc.)
2. Use a simple text-based generator
3. Convert `sidebar-icon.svg` to a 128×128 PNG and add a colored background

Place the file here as `icon.png` and the build will pick it up automatically (referenced in `package.json`).
